If you've ordered design work and been told your files are "vector" or asked whether you need "the vector version," and weren't entirely sure why it mattered — it's a genuinely important distinction for anything that's going to be printed, embroidered, or reproduced at more than one size.

## The actual difference

A raster image (JPEG, PNG, most photos) is built from a fixed grid of pixels — a specific number of coloured dots, at a specific resolution. Zoom in far enough, or scale it up beyond its original size, and those individual pixels become visible as blocky, blurry edges. A vector image (built in software like Illustrator, saved as Ai, EPS, or vector PDF) is built from mathematical paths and shapes instead — lines and curves defined by equations, not fixed dots. A vector image can be scaled to any size — a business card or a billboard — with perfectly crisp edges every time.

## Why this specifically matters for apparel and pattern design

A polo shirt design might need to appear at several different sizes — a small embroidered version on a left chest, a larger printed version on a back panel, potentially resized again for a hang tag or packaging. A raster file created at one size doesn't scale cleanly to a much larger size without visible quality loss. A vector file scales to any of these needs from the same original artwork with no quality loss at all.

It also matters directly for production: many printing and embroidery digitizing processes work from vector files specifically, because the clean paths translate more accurately into the machine instructions those processes use — a raster file often needs to be redrawn as vector artwork before certain production methods can use it at all.

## When raster is actually fine

A final mockup image — a photo-realistic preview showing the design on the actual garment — is normally delivered as a raster image (JPEG or PNG), since it's meant to be viewed, not scaled or reproduced through another production process. Social media posts, website images, and anything purely for viewing are reasonably raster. The distinction matters specifically for files headed to a printer, embroiderer, or supplier.

## What to check you're actually getting

If you're ordering design work meant to go into production, confirm you're receiving an editable vector source file (Ai or vector PDF), not just flattened JPEG or PNG exports. A designer who can only hand over raster files either isn't working in vector to begin with, or isn't including the source — either way, it's worth asking about directly before you commit to an order.

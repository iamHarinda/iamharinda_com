Getting a finished design back and seeing a folder full of files with unfamiliar extensions, Ai, EPS, PDF, PNG, JPG, is a common moment of "which of these do I actually need?" Here's what each format is really for, so you know exactly what to hand a printer, a supplier, or just keep for your own records going forward.

## Ai, an Adobe Illustrator file

This is the editable source file, the actual working file with every layer, path, and element still fully editable inside it. This is what you'd need if you, or a different designer later on, ever want to modify the design. It requires Adobe Illustrator or compatible software to open and edit properly. Think of this as the master copy, the one you never want to lose track of.

## EPS, or Encapsulated PostScript

A vector format similar in purpose to Ai, but more universally compatible across different design software. Some printers and older systems specifically request EPS because it's a more standardized vector format than Ai happens to be. If a supplier asks for a vector file and doesn't specify Ai directly, EPS is a safe alternative to have ready on hand.

## PDF, specifically vector, print-ready

A vector PDF preserves the scalability of the original design while staying viewable by essentially anyone, without needing any design software at all. Useful for sharing with a printer, a supplier, or anyone who just needs to see and use the artwork without editing it themselves.

## PNG

A raster, pixel-based image format that supports transparency, meaning the background can be see-through rather than a solid white box sitting behind it. This is the format you'd typically use for a logo or design that needs to sit on top of another image or background, like a website or a mockup you're building.

## JPG

Another raster format, but without transparency support, a solid rectangular image every time. Commonly used for photos and for viewing purposes, sharing on social media, in an email, in a presentation, rather than for actual production use down the line.

## Which one goes where

Sending to a printer or embroiderer for production, Ai or EPS, the editable vector source, is usually what they'll actually want, sometimes alongside a vector PDF as a backup. Using it on your own website or in a document, PNG if you need transparency, JPG if you don't. Sharing for approval or reference without needing to edit anything, PDF or JPG both work fine for that.

## What to make sure you actually receive

At minimum, the editable vector source, Ai or EPS, plus flattened versions, PNG and JPG, at high resolution. If you only receive flattened image files with no vector source included, that limits what you, or anyone else down the line, can actually do with the design later, resizing, recolouring, adapting it for a different use entirely.

Every order here includes Ai, PDF, PNG and JPG, the full set, not just a flattened preview handed over at the end.

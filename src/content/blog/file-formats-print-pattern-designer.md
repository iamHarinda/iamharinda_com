Getting a finished design back and seeing a folder of files with unfamiliar extensions — Ai, EPS, PDF, PNG, JPG — is a common moment of "which of these do I actually need?" Here's what each format is actually for, so you know what to hand to a printer, a supplier, or just keep for your own records.

## Ai (Adobe Illustrator file)

This is the editable source file — the actual working file with every layer, path and element still fully editable. This is what you'd need if you (or a different designer later) ever want to modify the design. It requires Adobe Illustrator or compatible software to open and edit. Think of this as the "master copy."

## EPS (Encapsulated PostScript)

A vector format similar in purpose to Ai, but more universally compatible across different design software — some printers and older systems specifically request EPS because it's a more standardized vector format than Ai. If a supplier asks for a vector file and doesn't specify Ai, EPS is a safe alternative to have on hand.

## PDF (vector, print-ready)

A vector PDF preserves the scalability of the original design while being viewable by essentially anyone, without needing design software — useful for sharing with a printer, a supplier, or anyone who just needs to see and use the artwork without editing it.

## PNG

A raster (pixel-based) image format that supports transparency — meaning the background can be see-through rather than a solid white box. This is the format you'd typically use for a logo or design that needs to sit on top of another image or background, like a website or a mockup.

## JPG

Another raster format, but without transparency support — a solid rectangular image. Commonly used for photos and for viewing purposes (sharing on social media, in an email, in a presentation) rather than for production use.

## Which one goes where

- **Sending to a printer or embroiderer for production:** Ai or EPS (the editable vector source) is usually what they'll actually want, sometimes alongside a vector PDF.
- **Using on your own website or in a document:** PNG (if you need transparency) or JPG (if not).
- **Sharing for approval or reference, without needing to edit:** PDF or JPG both work fine.

## What to make sure you actually receive

At minimum, the editable vector source (Ai or EPS) plus flattened versions (PNG, JPG) at high resolution. If you only receive flattened image files with no vector source, that limits what you (or anyone else) can do with the design later — resizing, recolouring, or adapting it for a different use.

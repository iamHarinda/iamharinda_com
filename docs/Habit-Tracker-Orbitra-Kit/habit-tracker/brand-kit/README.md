# Brand Kit — Habit Tracker by Orbitra

Open **`BRAND_GUIDELINES.html`** in a browser for the visual brand book.

| Folder | Contents |
|---|---|
| `logo/svg/` | Master vector logos — app icon, marks (light/dark/mono), horizontal & stacked lockups, Orbitra logos |
| `logo/png/` | PNG exports of every master + `sizes/` (16–512 px app icon) |
| `app-icons/android/` | Adaptive icon foreground / background / monochrome (Android 13 themed icons), splash icon — copy to the Expo `assets/` folder |
| `play-store/` | 512×512 Play icon, 1024×500 feature graphic |
| `social-media/habit-tracker/` | Profile pictures (Instagram, Facebook, X, LinkedIn, YouTube, TikTok, Threads) + covers (X, LinkedIn, Facebook, YouTube) |
| `social-media/orbitra/` | Same set for the Orbitra developer brand |
| `tokens/design-tokens.json` | Colours (light/dark), type scale, spacing, radius, motion |
| `tokens/theme.ts` | The same tokens as a React Native theme file |
| `tokens/brand.json` | Names, taglines, store text, voice rules |
| `tokens/app.json` | Expo config for `com.orbitra.habittracker` (icons, splash, permissions, Firebase) |
| `tokens/firebase.json` | Firebase defaults — analytics **off until consent**, no ad ID |
| `fonts/` | Inter + Inter Display (SIL Open Font License) |
| `source/generate_brand_kit.py` | Script that generated every logo/image (edit colours here and re-run) |

**Colours:** Navy `#14213D` · Coral `#FF6B4A` · Teal `#2EC4B6` · Sun `#FFC857` · Cream `#FFF8F0` · Ink `#0B1220` · Slate `#5C6B7A`

**Wordmark note:** SVG lockups use live Inter text. Install the fonts in `fonts/` before editing SVGs in Figma/Illustrator, or use the PNGs.

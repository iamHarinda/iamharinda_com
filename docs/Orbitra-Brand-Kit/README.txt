ORBITRA BRAND KIT
=================
svg/  Vector logos (best quality, any size)
png/  Transparent PNGs (app icon 512x512 is ready for the Google Play Console developer icon)
jpg/  JPGs on a white background

brand-guidelines.md  Brand book: idea, voice, colours, type, sub-brands
logo-usage.md        Logo files, clear space, minimum sizes, don'ts
design-tokens.json   Colours (light + dark), type scale, spacing, radius

CORE COLOURS (light theme)
  Solar orange   #FF5A1F   brand, mark, primary buttons (ink text on it)
  Solar text     #B93A0B   links and orange text
  Ion teal       #1C9C8C   secondary accent
  Halo           #FFD8C4   soft orange tint
  Deep / Ink     #0F1222   deep-space navy, primary text
  Ink muted      #565B6E   secondary text
  Surface        #F7F4EE   page background
  Raised         #FFFFFF   cards
  Line           #E4DFD4   borders

FONTS (free on Google Fonts)
  Space Grotesk  headlines + wordmark
  Inter          UI and body text
  JetBrains Mono code

NOTE: The PNG/JPG lockup was rendered with a fallback font because Space Grotesk
was not installed when exporting. Install Space Grotesk, open svg/orbitra-lockup.svg
in Figma or Illustrator, convert the text to outlines and re-export for final use.
